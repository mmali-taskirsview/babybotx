# BabyBotX — Complete Build + Test + Launch Prompt

Build, test, and launch a production-ready, secure, multi-language, geo-aware e-commerce website for BabyBotX (https://babybotx.com) that sells SERVICE ROBOTS as one-time purchases.

- Name: BabyBotX
- Domain: https://babybotx.com
- Tagline: "Your Home. Your Business. Our Robots."
- Email: business@babybotx.com / orders@babybotx.com

## Stack
Next.js 14 (App Router) + TypeScript (strict), Tailwind CSS + shadcn/ui + Framer Motion, next-intl (i18n), Prisma ORM + PostgreSQL (SQLite local), NextAuth.js, Zustand + React Query + React Hook Form + Zod, Resend + Pino + Sentry, Upstash Redis + Cloudflare Turnstile, bcryptjs + isomorphic-dompurify, Vitest + Testing Library + Playwright + MSW + axe-core, Deploy: Vercel.

## Design
Futuristic premium (Apple meets Tesla meets iRobot). Colors: Cyan #00E5FF · Navy #0A0E27 · Violet #7C3AED · White #F8FAFC. Fonts: Space Grotesk (headings) · Inter (body). Dark mode default, glassmorphism, responsive, WCAG 2.1 AA, RTL for Arabic.

## Business
One-time purchases of service robots: cleaning · delivery · security · lawn · kitchen · warehouse.

## Multi-language (12 locales)
en de fr es it pt nl ar ru ja ko zh — next-intl with /[locale]/... routing. Middleware priority: NEXT_LOCALE cookie > request.geo.country > Accept-Language > en. Country → language map included. Language switcher, translated strings, Intl formatting, hreflang, sitemap, RTL.

## Pages (all /[locale]/...)
Home · /shop · /shop/[slug] · /categories · /categories/[slug] · /cart · /checkout · /checkout/success · /checkout/cancel · /account · /login · /signup · /reset-password · /about · /contact · /faq · /terms · /privacy · /refund-policy · /shipping-policy

## Payments (worldwide)
Pluggable providers in /lib/payments/. Launch tier fully working: Stripe · PayPal · Alipay Global · WeChat Pay v3 · BankTransfer. Tier 2 stubs env-gated: Adyen · Razorpay · Paystack · MercadoPago · Mollie · Klarna · Afterpay · PayTabs · Midtrans · Xendit · Wise · GoCardless. Hosted checkout ONLY — PCI SAQ-A. API routes: GET /api/payments/providers?country=XX, POST /api/checkout, POST /api/webhooks/[provider], GET /api/orders/[sessionId].

## Database (Prisma + PostgreSQL)
Models: User · Category · Product · Order · OrderItem · Review · Address · SecurityLog. i18n JSON fields for name/description. Order.providerRef @unique (idempotency). OrderItem stores name snapshot. SecurityLog audit trail. Seed: 12 products across 6 categories with translations.

## Security (non-negotiable)
Headers (middleware.ts): HSTS · nosniff · X-Frame-Options DENY · Referrer-Policy · Permissions-Policy · COOP · CORP · strict CSP (Stripe, PayPal, Alipay, WeChat, Turnstile allowlist) · HTTPS only. Auth: httpOnly + secure + sameSite cookies, bcrypt ≥ 12, 12-char min passwords (NIST 800-63B), HIBP check, 5 failed logins → 15-min lockout, email verify before checkout, single-use reset tokens (15-min expiry, hashed), optional TOTP 2FA. Input: Zod .strict() everywhere, NEVER trust client prices, DOMPurify on user content, 100 KB JSON max, MIME magic-byte checks. Payments: hosted checkout only, verify ALL webhook signatures, idempotency via Order.providerRef, status ONLY from verified webhooks, Stripe Radar, redact PII. Rate limit (Upstash Redis): /api/checkout 10/min, /api/auth/* 5/min, /api/contact 3/hr, /api/newsletter 3/hr, /api/reviews 5/hr/user. Turnstile on signup/reset/contact/newsletter. Secrets: env vars only, .env.local gitignored, .env.example placeholders, rotate 90 days, NEXTAUTH_SECRET ≥ 32 bytes, gitleaks pre-commit, no NEXT_PUBLIC_ on secrets. Logs: Pino structured JSON, SecurityLog table, redact PII (u***@example.com), never log passwords/tokens/cards/CVV, Sentry with PII scrubbing. Privacy: cookie consent banner granular opt-in, /privacy page, account deletion soft-delete + 30-day purge, data export /api/account/export (JSON). Email DNS: SPF v=spf1 include:_spf.resend.com ~all, DKIM via Resend, DMARC v=DMARC1; p=quarantine; rua=mailto:business@babybotx.com.

## CI/CD
GitHub Actions: npm audit, tsc, ESLint-security, gitleaks, missing-translation check. Branch protection on main. Vercel previews password-protected. Production only from main after CI passes.
